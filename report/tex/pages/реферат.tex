\section*{Реферат}
\addcontentsline{toc}{section}{Реферат}

Отчёт посвящён выполнению практических работ по дисциплине <<Функциональное программирование>>. В рамках работ были реализованы функции на языке Haskell, пользовательские типы данных, представители классов типов, парсеры, проект обработки изображений, поиск пути в лабиринте с использованием монады RWS, текстовая игра с собственным трансформером \mintinline{haskell}{MyStateT}, а также тесты свойств с использованием QuickCheck.

Особое внимание уделено вопросам защиты: построению функции типа \mintinline{haskell}{Either (a -> a) (c -> c) -> [a] -> [c] -> [(a, c)]}, выражению с applicative-оператором \mintinline{haskell}{(<*>)}, объяснению применения RWS, порядку терминирования трансформеров и местам вызова \mintinline{haskell}{IO}. В отчёте приведены названия коммитов по каждой практической работе и указано использование нейросетей, отражённое в файлах практик.
