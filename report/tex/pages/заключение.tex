\section{Заключение}
\label{sec:conclusion}

В ходе курсовой работы был разработан программный комплекс для статического анализа растровых шрифтов в формате BDF. Программа реализована на языке Haskell и собирается с помощью Stack.

В проекте реализованы чтение и разбор BDF-файлов, расчёт метрик глифов, обнаружение аномалий, построение базы эталонных глифов, подбор замен из шрифта, заданного в конфигурации, логирование событий и формирование текстового отчёта. Отчёт содержит числовые значения метрик, описание нарушенных критериев, изображения анализируемых глифов и изображения предложенных замен.

\subsection{Результаты тестирования}

Для проверки корректности отдельных частей программы используются тесты свойств QuickCheck. Проверяются следующие свойства:

\begin{itemize}
    \item плотность глифа находится в диапазоне от 0 до 1;
    \item читаемость глифа находится в диапазоне от 0 до 1;
    \item для каждого глифа шрифта рассчитывается ровно одна запись метрик;
    \item нормальные значения метрик не классифицируются как аномалии.
\end{itemize}

Тесты запускаются командой \texttt{stack test}. Дополнительно проект проверялся запуском анализа на BDF-файлах из каталога \texttt{data} и на пользовательских файлах \texttt{dina-8.bdf}, \texttt{dina-10.bdf}.
